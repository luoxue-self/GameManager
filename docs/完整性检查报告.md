## 8. 安全与数据

- 密码使用 **scrypt** 哈希，不存明文；
- 会话 Cookie 为 `httponly`、`samesite=lax`，可选 `secure`（HTTPS 环境）；
- 同一 IP 连续失败 8 次锁定 5 分钟；
- 未登录访问 API 和封面图均返回 401；
- API 响应带 `Cache-Control: no-store`、`X-Content-Type-Options: nosniff`、
  `X-Frame-Options: SAMEORIGIN`、`Referrer-Policy: same-origin`；
- 封面路径校验 basename，禁止 `..` 穿越；
- 上传图片经 Pillow 验证并限制 8MB；xlsx/zip 限制 30MB，解压总量限制 200MB；
- 备份 zip 不包含 `.secret`，只含数据库、图片和恢复说明；
- 仓库不含任何运行时密码、密钥或用户数据。

## 9. 本轮发现并修复的问题

| # | 问题 | 影响 | 修复 |
|---|---|---|---|
| 1 | 导入「更新已有」时，库中存在多条近似同名记录会重复匹配第一条 | 第二条无法更新，统计为跳过 | 新增 `_match_existing`：完全同名 > 归一化同名 > 最佳相似度；补充回归用例 |
| 2 | 编辑弹窗「游戏名 *」星号被 flex 布局挤到下一行 | 表单观感差 | 标签文字与 `*` 包进同一个 `<span>` |
| 3 | exe 用户忘记密码无法自助恢复（原来只能改数据库/有 Python） | 普通用户被锁在门外 | 新增 `--reset-password` 与 `重置密码.bat`，弹窗显示新密码并写入文件 |

> 另外，打包时发现测试 exe 未退出会锁定 `data/启动日志.txt` 导致构建失败；

## 10. 已知限制

1. Windows exe 需要 **Edge WebView2 Runtime**；Windows 10 1803+ / 11 一般自带。
2. 桌面窗口默认**隐私模式**：关闭后不保留登录状态与排序偏好；网页模式会保留 7 天登录。
3. SQLite 是单机数据库：**不要多人同时共享同一个 `data` 文件夹**；多人使用请走网页模式。
4. 公网访问网页模式必须套 HTTPS，否则密码与 Cookie 明文传输。
5. 图片按原样保存（上传会压缩，Excel 导入不压缩），超大封面建议手动压缩。
6. 文档路线图中的**别名表、多用户隔离、标签、游戏时长、云同步、语义搜索**尚未实现。
7. `build.py` 会清空 `dist/`，重新打包前需自行备份 `dist/游戏库管理器/data/`。
8. 当前 GitHub Actions 尚未在远端实际运行；本机已用等价命令完成打包验证。
