## 4. 凭证与权限清理

本次上传没有创建个人访问令牌（PAT），使用的是 GitHub OAuth 设备码/浏览器授权。

| 项目 | 处理 |
|---|---|
| 设备码临时 Token 文件 | 已删除（`%TEMP%\gm_github_token.txt`） |
| Windows 凭据 `git:https://github.com` | 最终推送完成后从凭据管理器移除 |
| Git Credential Manager 中的 `luoxue-self` | 最终推送完成后 `git-credential-manager github logout luoxue-self` |
| 仓库内凭证 | 无 |
| DeepSeek Harness 权限 | 本次会话结束后关闭工具窗口；如不再使用，可结束会话 |

> 移除 GCM 凭据后，下次执行 `git push` 会重新弹出 GitHub 登录窗口，这是正常的安全行为。
> 如希望同时撤销 GitHub 侧授权，可到 GitHub：Settings → Applications → 已授权 OAuth Apps 中移除。
